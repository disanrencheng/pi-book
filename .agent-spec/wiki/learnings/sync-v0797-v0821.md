# 同步轮 v0.79.7→v0.82.1 漂移与修订记录

2026-07-25/26 完成的第二轮同步。区间:pi-mono `c4ab61dc`(v0.79.7)→`b4f29368`(v0.82.1),
515 commits、18 releases。工作流:4 个并行勘察 agent 逐包提炼 changelog →
5 份 update-v082-* 合约(lint 100%)→ 5 个执行 agent 分两波修订 27 章 →
三视角评审(fact/tech/structure)→ 23 项修复。

## 核心漂移(按冲击排序)

1. **pi-ai v0.80.0 全局性 breaking**:`api-registry.ts`/`stream.ts`/文本侧
   `register-builtins.ts` 删除,代之以显式 `Models`/`Provider` 集合
   (`models.ts`);旧全局 API 迁 `/compat`。
   → ch04 全章重写,主线改为「隐式全局单例 → 显式依赖注入集合」。
2. **pi-ai v0.80.0 引入、v0.80.8 收口认证子系统** `src/auth/`:
   `ProviderAuth`/`CredentialStore`/`OAuthAuth`;六回调收敛为
   `AuthInteraction.prompt()/notify()`;错误信息策略反转(`ModelsError` 保留
   cause)。→ ch07 全章重写为「认证是一等子系统」。
3. **类型名迁移与新运行时接口并存**:`types.ts` 中表示 `model.provider` ID 的旧
   `Provider` alias 改名为 `ProviderId`；不要与 `models.ts` 新增的运行时
   `Provider` interface 混为同一概念。coding-agent v0.80.8 中
   `ModelRuntime` 取代 `ModelRegistry`/`AuthStorage`
   成为规范门面;SDK `createAgentSession` 选项改 `modelRuntime`。
   → ch18/ch26b 示例重写。
4. **结构扩张**:4 包→7 workspace 包(+server/storage/sqlite-node/evals),
   build 4 步→6 步。→ ch02 标题改为计数无关的「包不是项目」,
   续写 3→7→4→7 曲线。
5. **agent 包**:runLoop 必填 `streamFunction` + `setDefaultStreamFn` 兜底
   (0.81.0/0.81.1);`AgentHarnessTool<TContext>`(0.82.0 breaking)。
6. **tui**:书稿光标模型补缺——反色软件光标 + IME 用硬件光标叠加层。

### 固化的源码证据

- agent loop 无 module-level 持久状态；调用方提供独立 context 时可重复调用和组合，
  但会直接修改传入 context 并执行 LLM/tool I/O，因此不是纯函数，也不保证共享
  context 时可重入（`packages/agent/src/agent-loop.ts:155-220,281-370`）。
- Skill 名称冲突采用 first-wins；用户级默认目录先于项目级，冲突只记录
  diagnostic（`packages/coding-agent/src/core/skills.ts:394-425,430-432`）。
- stream `partial` 表示发射时的累计消息状态，但协议不保证对象身份或不可变性。
  Anthropic adapter 复用可变 accumulator，faux provider 发射浅拷贝；消费者若要
  保存历史或恢复必须显式 clone/serialize（`packages/ai/src/types.ts:483-503`；
  `packages/ai/src/api/anthropic-messages.ts:567-703`；
  `packages/ai/src/providers/faux.ts:316-390`）。
- 项目 AGENTS.md/CLAUDE.md 从 cwd 及祖先链发现并注入 system prompt，
  不位于 `{cwd}/.pi/AGENTS.md`
  （`packages/coding-agent/src/core/resource-loader.ts:67-120`；
  `packages/coding-agent/src/core/system-prompt.ts:144-151`）。
- read 截断只限制进入模型的内容，完整文件仍先读入 `Buffer`
  （`packages/coding-agent/src/core/tools/read.ts:238-288`）。
- file mutation queue 只覆盖同一进程、同一规范化路径，不覆盖跨进程修改或
  外部 TOCTOU（`packages/coding-agent/src/core/tools/file-mutation-queue.ts:4-60`）。
